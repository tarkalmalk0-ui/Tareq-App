إخراج APK من الهاتف فقط

هذه الحزمة تحتوي مشروع Android Studio مع إعداد بناء تلقائي عبر GitHub Actions.

الخطوات:
1) أنشئ حساباً في GitHub إذا لم يكن لديك حساب.
2) أنشئ مستودعاً جديداً باسم tareq-android، واجعله Private إن رغبت.
3) ارفع جميع محتويات هذا المجلد إلى جذر المستودع (بما فيها مجلد .github المخفي).
4) افتح تبويب Actions في المستودع.
5) اختر Build Tareq APK ثم Run workflow.
6) بعد نجاح البناء، افتح عملية البناء نفسها وانزل إلى Artifacts.
7) نزّل Tareq-debug-apk.zip إلى الهاتف، وافتحه لاستخراج app-debug.apk.
8) افتح APK واتبع تعليمات أندرويد للتثبيت.

ملاحظات:
- البناء يتم على خوادم GitHub؛ يلزم الإنترنت لرفع المشروع وتنزيل APK فقط.
- بعد تثبيت التطبيق، وظائف الفواتير تعمل محلياً دون إنترنت.
- لا تشارك كلمة مرور حسابك أو رموز الدخول مع أي شخص.
- لا ترفع مفاتيح توقيع أو أسرار إلى المستودع.
- ملف APK الناتج Debug للاختبار الشخصي.
