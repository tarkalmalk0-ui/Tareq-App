مشروع تطبيق طارق للأندرويد

المواصفات:
- اسم التطبيق: طارق (TAREQ)
- العملة: الدولار الأمريكي
- يعمل دون إنترنت؛ واجهة التطبيق محفوظة داخل APK.
- الفواتير تُحفظ محلياً على الهاتف باستخدام مساحة تخزين التطبيق.
- يعرض إجمالي مبيعات الشهر الحالي وعدد الفواتير اعتماداً على تاريخ كل فاتورة.
- إضافة وتعديل وحذف الفواتير والمواد.
- الطباعة عبر خدمة الطباعة في أندرويد، ومنها يمكن اختيار حفظ PDF.

مهم:
هذا مشروع Android Studio كامل المصدر، وليس ملف APK جاهزاً. بيئة العمل الحالية لا تحتوي Android SDK أو Gradle أو أدوات بناء أندرويد، لذلك لم أتمكن من تجميع APK هنا.

لبناء APK:
1. نزّل Android Studio على كمبيوتر.
2. افتح مجلد TareqAndroid في Android Studio.
3. اسمح له بتنزيل مكونات Gradle وAndroid SDK المطلوبة.
4. من القائمة اختر Build ثم Build Bundle(s) / APK(s) ثم Build APK(s).
5. ستجد الملف عادةً في app/build/outputs/apk/debug/app-debug.apk.

لا يحتاج التطبيق إلى صلاحية إنترنت، ولا يرسل الفواتير إلى أي خادم.
تنبيه: بيانات التطبيق محلية؛ لا تحذف بيانات التطبيق أو تزل تثبيته دون أخذ نسخة احتياطية من الفواتير.
